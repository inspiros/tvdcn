# Repository instructions

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It
holds the repository conventions, native-code rules, file placement and
validation rules.

To resume work, start with `.agent-notes/resume.md`: current state, decisions
in force, open items and the next step. That folder is local and gitignored;
if it is absent, ask the maintainer for the current scope. Read
`.agent-notes/lab_workspace.md` before any remote build or GPU validation.
